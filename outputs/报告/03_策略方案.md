## 1. 现状审计：钱花在哪、换回什么

口径：补贴 = 完成券的 reward 之和；GMV = 完成券的 difficulty 之和（门槛口径）；账面净额 = GMV − 补贴。

| 高价值·选择性 | 3,650 | 17,388 | 8,524 | 49.0% | 38,960 | 77,150 | 38,190 | 1.98 | 38,190 |

\*增量净额口径：只有"选择性响应型"的 GMV 视为增量，其余人群 GMV 记为 0（全响应人群本来就会买，零完成人群根本没买）。这是保守口径，不是因果结论。

三个直接发现：

1. **补贴高度集中**：高价值·全响应 4,832 人（28.4% 用户）吃掉 87,538 元补贴（53.2%），贡献 17,144 次完成（51.1%）。他们的可完成券完成率是 100%——券对他们是"顺手就用"，不是"因为券才买"。
2. **零完成人群不花补贴，但浪费触达**：三个零完成人群合计 3,496 人（20.6%），13,275+1,755+79 = 15,109 次触达，0 次完成。他们不是没看到（查看率约 70%），是门槛打不到。
3. **选择性人群是唯一"券能改变行为"的池子**：7,121 人（41.9%），贡献 14,431 次完成（43.0%）、66,705 元补贴（40.5%）。高·选择性 ROI 1.98，是现状里最高的。

## 2. 策略矩阵：人群 × 券型

矩阵的读法：每个格子是"该人群收到该类券的历史完成率 / 每千次触达的净 GMV"。净 GMV = 完成率 × (difficulty − reward) × 1000。

### 2.1 关键矩阵（净 GMV / 千次，括号内为完成率）

| 人群 | BOGO 5/5 | BOGO 10/10 | 折扣 7-3 | 折扣 10-2 | 折扣 20-5 | 信息型 |
|---|---|---|---|---|---|---|
| 高·全响应 | 0 (100%) | 0 (100%) | 4,000 (100%) | 8,000 (100%) | **15,000 (100%)** | 0 (0%) |
| 高·选择性 | 0 (60%) | 0 (39%) | 3,388 (85%) | 5,831 (73%) | **5,947 (40%)** | 0 (0%) |
| 中·全响应 | 0 (100%) | 0 (100%) | 4,000 (100%) | 8,000 (100%) | **15,000 (100%)** | 0 (0%) |
| 中·选择性 | 0 (50%) | 0 (35%) | 2,363 (59%) | 4,225 (53%) | **4,359 (29%)** | 0 (0%) |
| 中·低活跃 | 0 (16%) | 0 (17%) | 575 (14%) | **1,514 (19%)** | 1,449 (10%) | 0 (0%) |
| 高·零完成 | 0 | 0 | 0 | 0 | 0 | 0 |
| 中·零完成 | 0 | 0 | 0 | 0 | 0 | 0 |
| 低·零完成 | 0 | 0 | 0 | 0 | 0 | 0 |
| 低·低活跃 | 0 | 0 | 0 | 18 (0.2%) | 0 | 0 |

### 2.2 矩阵读出的四条规则

- **BOGO 的净 GMV 恒为 0**：BOGO 的 reward = difficulty（买一送一），每完成一单，补贴等于门槛金额，净额天然为 0。它可能带来客流，但在这套口径下不产生净收入。现状却把 BOGO 10/10 当成高·选择性、高·零完成的主投券种——这是结构性问题。
- **折扣券是唯一正净额券种**：折扣 20-5 的单次净额最高（15 元/单），但完成率低；折扣 10-2 单次净额 8 元、完成率高。两者的取舍不能只看"每千次净 GMV"。
- **全响应人群的矩阵是"假繁荣"**：所有券 100% 完成、折扣 20-5 每千次净 15,000，但这恰恰说明券不是增量。矩阵只能说明"发了他会用"，不能说明"不发他就不买"。
- **零完成人群对所有券都是 0**：不是券型选错，是门槛整体高于其客单。高·零完成消费中位 32 元、交易 12 笔（客单约 2.7 元）；中·零完成消费 12.3 元、交易 5 笔（客单约 2.5 元）。现有最低门槛 5/7 都打不到。

### 2.3 为什么高·选择性不选"净 GMV 最高"的折扣 20-5

| 券种 | 完成率 | 每千次净 GMV | 单次补贴 |
|---|---|---|---|
| 折扣 20-5 | 39.6% | 5,947 | 5 |
| 折扣 10-2 | 72.9% | 5,831 | 2 |

折扣 20-5 的净 GMV 只高 **2%**，但完成率低 **33pp**、单次补贴高 2.5 倍；而且 02 已证明该人群明确偏好低门槛（hard−easy = −0.196）。为了 2% 的净额去牺牲 33pp 的完成率和客户体验不划算。因此设定**稳健性规则**：净 GMV 在最优值 95% 以内的券种视为同一档，同档内选完成率更高的。中·选择性同理（4,359 vs 4,225，差 3%，完成率 29% vs 53%），也选折扣 10-2。

这条规则是这次策略里最值得写进简历的"判断"：**指标最优不等于决策最优，要结合完成率、补贴成本和人群偏好。**

## 4. 预算模拟：S0 现状 vs S1 优化

### 4.1 假设（必须先说清楚）

1. **保持触达量不变**：每个人群的总触达次数与现状相同（76,277 次），只切换券型结构；信息型触达按 0 补贴成本计。
2. **用历史完成率外推**：S1 的完成率取自矩阵中"该人群收到该券种"的历史观测值。这不是随机实验，存在选择偏差（收到 d10 的人可能本来就更容易转化）。
3. **账面口径**：GMV = 完成券 difficulty 全额；**增量口径（保守）**：只有选择性人群的 GMV 算增量，全响应/零完成人群的 GMV 记为 0。
4. 30 天窗口、无对照组、无季节因素；这些局限在 04/05 用响应模型和 uplift 继续处理。

### 4.2 结果

| 指标 | S0 现状 | S1 优化 | 变化 |
|---|---|---|---|
| 触达 | 76,277 | 76,277 | 0 |
| 完成 | 33,579 | 20,979 | −12,600（−37.5%） |
| 补贴 | 164,676 | 41,959 | **−122,717（−74.5%）** |
| GMV（账面） | 311,272 | 209,793 | −101,479（−32.6%） |
| 账面净额 | 146,596 | 167,835 | **+21,239（+14.5%）** |
| 增量 GMV | 129,222 | 209,793 | +80,571（+62.3%） |
| 增量净额 | −35,454 | 167,835 | **+203,289** |
| ROI（账面） | 1.89 | 5.00 | +3.11 |
| ROI（增量） | 0.78 | 5.00 | +4.22 |

### 4.3 怎么解释"GMV 降了 32.6%，净额反而涨了 14.5%"

- 账面 GMV 下降，主要是**主动停掉了全响应人群的 16.3 万 GMV**。这部分 GMV 大概率是"本来就会发生"的，继续补贴只是在为自然成交买单。
- 补贴降得更狠（−12.3 万），所以账面净额仍上升 2.1 万；增量净额从 −3.5 万转为 +16.8 万，改善 20.3 万。
- **这不是"放弃 GMV"，而是"挤掉伪增量"**：S1 的 20.98 万 GMV 全部来自选择性人群，是券真正可能改变行为的部分。
- 代价是完成次数从 33,579 降到 20,979（−37.5%），短期报表上的"核销率"会变难看；需要用增量净额而不是核销率来考核。

## 5. 风险与局限

1. **没有对照组**：所有"增量"都是假设，不是因果证明。全响应人群到底有多少是自然购买，只有 uplift 模型/实验能回答。
2. **券型完成率存在选择偏差**：历史投放不是随机的，某人群收到 d10 的比例、时机、频次都可能不同。S1 外推只能当"方向性测算"，不能当承诺。
3. **停发券的反弹风险**：全响应人群被停券后，可能流失一部分；这份数据没有"停发后的对照"，04 需要用模型估计。
4. **BOGO 净 GMV 为 0 是口径定义**：BOGO 可能带来客流和连带销售，但 difficulty 口径下无法体现，不能据此说 BOGO 一无是处。
5. **时段优化做不了**：02 已证明四个时段占比各约 25%，这份数据没有时段偏好信号，只能给到 4 档粒度。
6. **中·低活跃 381 人样本小**：其 19% 完成率可能是噪声，不建议单独配预算。
